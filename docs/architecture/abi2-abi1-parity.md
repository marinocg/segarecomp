# ABI 2 / ABI 1 parity matrix

Status: verified 2026-11-22 against product `main` `da82cf0` and `segarecomp-patches` `32eb7d4` (SEG-152-T002). The decisions that close every open row are in [ADR 0320](../decisions/0320-abi-2-exact-frame-presentation-and-parity-contract.md); the scenery rows rest on [widescreen scenery window sufficiency](widescreen-scenery-window-sufficiency.md). "Decided, implemented by SEG-152-Txxx" marks what no code does yet. Nothing in this document changes behaviour.

## 1. What is being compared

**ABI 1** is the native patch provider the three production widescreen packages use (`segarecomp_patch_provider`, a `GenesisNativeCompat` table: `prepare`, `scenery_word`, `hud`; declared in `platforms/genesis/runtime/vdp_render.h`). The extension producer (`genesis_vdp_produce_extension`, `vdp_render.c`) calls it for the frame it is producing, with that frame's own raster state and the work-RAM copy of the previous onset.

**ABI 2** is the scheduled mod ABI (`platforms/sdk/segarecomp_mod.h`, `platforms/genesis/sdk/segarecomp_mod_genesis.h`). Its host, `platforms/genesis/viewer/mod_capture.cpp`, *is itself an ABI 1 provider* to the producer (`kTable`, line 505: `prepare`, `scenery_word`, `hud`): ABI 2 render output reaches the screen through the same producer, compositor and virtual-sprite transport. There is no second renderer; parity is an adapter and contract question.

## 2. Verified timeline and the critical gap

`runtime.c` 3050-3070, `mod_scheduler.c` `hook_after_snapshot` (423), `mod_capture.cpp` `prepare` (421): at the onset that ends guest frame `N`, `frame-end(N)` runs, the frame counter becomes `N + 1`, the producer runs (ABI 1 callbacks for **raster N**, RAM copy of the end of `N - 1`; `compat_ram_valid` requires `stamp + 1 == count`, `runtime.c` 2796), the snapshot is taken (end of N, `runtime.c` 2808), and ABI 2 `render(N)` runs from that copy. Its output is served only when `visible_frame + 2 == count`, that is, for **raster N + 1**. The full timeline table, with the RAM and VDP data each step sees, is in ADR 0320.

Consequences, each tied to a matrix row:

1. `render(N)` has no raster N + 1 to verify against its RAM snapshot or to draw its HUD from; the three ABI 1 providers do exactly that (rows 2, 3, 8, 11).
2. `genesis_mod_scheduler_supported()` omits `SEGA_MOD_CAP_FRAME_VDP` (`mod_scheduler.c` 21-27); a required `frame.vdp` is refused at attach, VDP spaces return `SEGA_MOD_E_SPACE` in `render`, and `SegaGenesisFeatures` (`segarecomp_mod_genesis.h` 65-71) has no frame pointer. The ABI 2 documents promise `frame.vdp` copies in `render` (`mod-execution-phases.md` section 2): the contract is ahead of the implementation.
3. The scheduled-mod presenter is viewer-only (`SEGARECOMP_MOD_VIEWER`); a headless program has no extension producer. "Headless versus SDL consistency" therefore means the shared frame artifact plus the SDL viewer under the dummy video driver; T008 states it that way.

### Row 6 in one paragraph

A window is addressed by the **plane cell the host derives from the line's real scroll**: `floor((x - hscroll) / 8)`, `floor((line + vscroll) / 8)`. Because the VDP reports `hscroll` as a 10-bit signed value, every scroll lies in -512..511, so the plane columns one plane needs are bounded by `(picture + 2 * side) / 8 + 128` cells; two 128-column windows therefore cover every scene up to a total width of 1024 pixels (32:9 is 796): **geometry is sufficient** (measured on Sonic 1, Sonic 2 and Sonic 3 & Knuckles scenes: never more than two windows per plane). **Answer representability is a different question**: a window holds one word per plane cell, so a coordinate that ABI 1 answers two ways inside a frame (a fallback line sharing a cell with an authored line, a registered-multiple change or a raster condition inside one plane cell row) cannot be expressed. The real Sonic 2 provider does this in Emerald Hill Zone 1 (136 of 269 accepted frames, plane A, up to 3 lines, an ideal window still differs in up to 2 pixel rows); the real Sonic 3 & Knuckles provider does not in Angel Island Zone 1 (0 of 1032); Sonic 1 is unmeasured. Hence `T007_REQUIRED` for the per-line fallback class only.

## 4. Intended differences (stated, not accidental)

| Difference | Why it is intended |
|---|---|
| ABI 2 has no per-pixel provider call: the host looks up bounded windows | the renderer never calls guest-influenced code in the per-pixel loop (ADR 0309); ABI 1's per-pixel calls cost 34,944 / 90,496 / 213,248 provider calls per produced frame at 16:9 / 21:9 / 32:9 against at most 4 x 4096 window words |
| An exact-frame provider cannot also use the predicted `render` timing | ADR 0320 D1; no consumer needs both |
| Refusal is a call with a bounded reason vocabulary, not a `prepare` return value | an ABI 2 callback returns nothing; the mapping onto `GenesisCompatDecision` is one to one (D7) |
| `frame.vdp` is required-only | a capability that selects callback timing cannot be optional (D2) |
| ABI 2 save state is the provider's `state.mod`, not an ABI 1 side channel | superseded (row 14) |

## 6. The parity gate (SEG-152-T008, Exit C)

The gate is validation only: it adds no API and no second comparison harness. It has two halves, both in public CI, both on project-authored synthetic content (no ROM, no vendor data).

| Half | Test | What it compares |
|---|---|---|
| producer | `abi_parity_gate_tests` (`tests/abi_parity_gate_test.cpp`, extending `tests/abi_parity_harness.hpp`) | One scene set run through the real extension producer twice: an ABI 1 provider and an ABI 2 twin written to the same game logic (`make_plan`). The twin submits scenery through the production windows and per-row mask (`scenery::answer`, `arm_twin`), the HUD through the production bitmap/overlay rules (`luau::overlay_bitmap`, `overlay_declare_bitmap_layer`, `overlay_layer_clip`, `overlay_fallback`, `overlay_scene`, `rasterize_*`, `pack_hud`) and refuses through the adapter's decline semantics. Compared per frame, component by component: accepted components, reason, surface, overlay, layers, scene token, placement shift and authored coverage (`presentation_mismatches`, one digest `presentation_digest` built on the harness's FNV-1a). |
| viewer | `mod_parity_gate_abi2_test` (`tests/mod_parity_gate_abi2_test.py`, fixtures `tests/fixtures/mod_parity/`) | The final presented frame through the SDL3 viewer and its one compositor: the schema 2 ABI 1 twin against the schema 3 package (`bps-image` + `native-c11`, capabilities `frame.vdp, frame.work_ram, overlay.rgba, scenery.words`, `abi.minor = 2`), 4 variants (served, per-row generic rows, refused HUD, refused frame) x 5 modes (32:9 with an asymmetric placement, 21:9, 16:9, Original, exact 4:3), byte for byte and against committed golden digests; the schema 3 package is accepted by the packager and byte-deterministic; the schema 2 package of the same game still builds. |

The producer half first runs the whole T001/T007 scenery suite (`run_scenery_suite`, included from `abi_parity_scenery_test.cpp`: one set of fixtures, one failure counter), then the presentation matrix: 9 scenes (per-line parallax, split scroll with vertical scroll, per-line palettes, a HUD drawn from the game's own tiles through the host's CRAM helper, a fade, an unsupported scene, a HUD-only scene, a refused HUD with per-row generic rows, a generic plane, a window-plane status band) x 4 aspects (Original/4:3, 16:9, 21:9, 32:9) x the ADR 0315 placement matrix (left, intermediate, centred, intermediate, right). Every (scene, aspect) has a golden digest in `abi_parity_gate_goldens.inc` (exact equality, no tolerance; regenerate with `abi_parity_gate_tests --print-goldens` only for an intended, reviewed change). Sequences cover the fade, aspect changes every frame, deterministic replay twice, a warm versus cleared provider-side window cache, save/load and rewind of that state, a genuine provider failure (an unanswered cell: the same FAULT verdict, authored 0, no residue) and the stale/out-of-range placement rule. A mandatory ledger (`completeness`, 188 cases) fails the gate when any required case did not run: every T001 scenario at three aspects and both timings, every T007 fixture (including `fallback-mid-cell`, the 448-row producer case and the code-3 gate), every presentation scene and aspect, every falsification and sequence.

**Falsification.** Seven mutants of the ABI 2 twin must fail a *named* assertion and their unmutated control must pass: a stale scroll (`surface`, `coverage`, `reason`), a stale cache key, a stale placement, a skipped callback (`accepted-components`), a missing refusal (`accepted-components`), a wrong refusal reason (`reason`), an oversized bitmap (`accepted-components`, `reason`: production semantics, an invalid render-API call faults the whole callback, discards everything staged and leaves accepted 0 / reason FAULT with no layer, scenery credit, placement or scene token; the model's `Twin::faulted` mirrors `mod_capture.cpp`'s `answer`). The viewer half falsifies a stale scroll (`picture`), a skipped callback and two missing refusals (`accepted-components`, `picture`) through per-frame verdict and picture comparison, and the oversized bitmap through the real SDL3 path: one `E_MOD_FAULT cause=range` on the render callback (SEGA_MOD_E_RANGE is the status the adapter returns, `genesis_mod_overlay_script_tests`), Vanilla's generic picture and guest RAM, and from that frame on the producer's verdict is accepted 0, reason FAULT, side planned, no placement, authored 0.

**Per-frame verdicts (viewer half).** For every variant and mode the `VIEWER_TEST_TRACE` of the ABI 1 twin and the ABI 2 package are compared frame by frame (frame identity, producer status, side, placement shift, accepted component mask, refusal reason, authored status) and the coverage report's offered/accepted/presented/rejected accounting is compared (declared/covered/requested depend on a geometry declaration the schema 2 twin cannot carry). Finding: in Original and exact 4:3 the ABI 1 twin is handed the planned side and requests a placement (`shift` -179 / -30) that the presenter ignores, while the ABI 2 view reports side 0 and cannot (ADR 0315): pictures are identical, the `shift` of the verdict differs. **Operator-reviewed exception (ADR 0315 presentation contract, accepted).** That is the ONE declared difference, and it is a hard-coded, narrow rule of `compare_contract`: only the placement `shift`, only on frames where the presenter shows no extension (Original, exact 4:3), only with the ABI 2 shift equal to 0, and only while the presented pictures are byte-identical (asserted for every variant and mode and for the transition run's final frame). Frame identity, status, side, accepted components, refusal reason, authored status and the coverage accounting must stay equal there; every other difference, and any difference on a frame where the extension is shown, is a hard failure. There is no tolerance, wildcard or normalization, and ABI 1 behavior is unchanged. The gate prints `DECLARED DIFFERENCE` with the frame count. Two earlier fixture asymmetries were fixed rather than excused: the ABI 2 fixture did not submit scenery in exact 4:3 (accepted 1/authored 0 against the twin's 3/1: it now submits for the host's `requested` mask with a nominal margin), and the ABI 1 twin reported no reason when refusing the HUD (the same-logic ABI 2 decline reports BAD_STATE).

**Lifecycle, real versus model.** Real viewer: the complete ordered `VIEWER_TEST_TRACE` is kept (repeated frame numbers after a rewind are not overwritten): the load must show a forward frame-number jump into the saved timeline, the rewind a backward jump with repeated frame numbers, and every occurrence (85 for the load, 123 for the rewind, per package) must equal the uninterrupted run's verdict for its frame number except the one newly produced frame after the restore (STALE_STATE). A scripted run through 32:9, 21:9, 16:9, Original, exact 4:3 and 32:9 (110-turn fixture), its replay, a quick save + load and a rewind, for both packages, with per-frame verdicts and final frame equal between the twins and equal to each package's own uninterrupted run (the one first frame after a restore is the host's STALE_STATE for both). Model-level only (not production restore code): the 24-frame `Session` sequences of the producer half. The viewer half runs 32:9, 21:9, 16:9, Original and exact 4:3.

**Watched, not parity.** `origin-multiple-mid-cell` and `raster-condition` keep failing as `LIMIT:condition-dependent` exactly as T001 recorded them (synthetic only, no real-provider scene exhibits them, not implemented). The gate asserts they still fail and never excuses a difference: a new difference needs the operator, not an exception in the gate.

**Not covered here, and where it is.** Virtual-sprite positioning (including `GENESIS_VSPRITE_SPACE_PRESENTATION`) needs the viewer compositor: `mod_vsprite_abi2_test`, `mod_exact_frame_abi2_test` and `mod_bitmap_abi2_test` (an authored sprite beside a refused HUD). The ADR 0315 viewport suites (`mod_view_abi2_test`, `mod_view_transitions_abi2_test`, `mod_scenery_abi2_test`, `mod_vsprite_abi2_test`) run unmodified in the same CI job. A genuine ABI 2 *callback* fault (invalid call, wrong phase, budget) is the viewer suites' (`mod_exact_frame_abi2_test`, `mod_bitmap_abi2_test`): the producer half injects the provider failure a host can observe, an unanswered cell. Guest save/load and rewind are the viewer suites' (`mod_exact_frame_abi2_test`); the producer half's cache, save/load and rewind sequences exercise a test-local model of provider-side state (determinism of the twin), not production restore code, and the 21:9 aspect is covered by both halves.

**Cost and memory** (`PARITY cost`/`PARITY memory` lines of the producer test, deterministic counts): the exact-frame view is 188,416 bytes copied by the host per produced frame (work RAM 65,536 + VRAM 65,536 + 224 line records x 256), immutable and host-owned; the overlay and layer buffers are the fixed 131,072 and 262,144 bytes both ABIs share; the staged bitmap transport is 9,472 bytes for the fixture HUD (budget 393,216 per callback); at 32:9 a centred ABI 2 frame answers the same 213,248 host cell queries from at most 8,146 window words (16,292 bytes) plus two 28-byte row masks, and the producer time of the two twins is equal within noise (informational, never asserted).
