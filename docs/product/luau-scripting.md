# Luau scripting for mods (restricted API, developer preview)

A mod can carry Luau scripts (`kind = "luau-source"`). Scripts are **restricted and limited**, not sandboxed or safe: see the [trust policy](../architecture/luau-trust-policy.md) and [ADR 0295](../decisions/0295-luau-host-api-static-check-and-fixture-session.md). In this release scripts are checked, compiled and run by the **deterministic fixture session** (`segarecomp mod session`); they are not yet run inside a game.

## The API (generated)

The complete list is [`api.json`](luau/api.json); the type declarations are [`segarecomp.d.luau`](luau/segarecomp.d.luau). Both are generated by `segarecomp mod api` from the single API table and checked by CI against these committed copies.

| Name | Capability | Phase | What it does |
| --- | --- | --- | --- |
| `sega.log(message)` | `host.log` | any | one log line (256 bytes, 16 lines per callback) |
| `sega.frame.value(name)` | `frame.work_ram` | render | a read-only copy of a named integer the host published for this frame, or nil |
| `sega.overlay.rect(x, y, w, h, rgba)` | `overlay.rgba` | render | filled rectangle in the 128x256 HUD overlay; `rgba` is `0xRRGGBBAA` |
| `sega.overlay.text(x, y, text, rgba)` | `overlay.rgba` | render | text in the host's bitmap font (printable ASCII, 64 bytes) |
| `sega.overlay.width` / `.height` | `overlay.rgba` | render | 128 / 256 |
| `reset()`, `render(frame)` | - | reset / render | optional callbacks you define as globals; `frame` is the frame counter |

Rules: integers only (a fraction, NaN, infinity or negative size is a `range` fault); coordinates are clamped to the overlay and reported as notes; at most 64 overlay requests per callback; a binding outside its phase is a `phase` fault. Values cross by copy; nothing aliases host memory. There is no guest-memory access, input, clock, file, network or randomness other than the deterministic `math.random`.

Declare every capability you use in `mod.toml` (`[capabilities] required = [...]`). `segarecomp mod check` rejects an undeclared use (`E_LUAU_CAPABILITY`), an unknown name (`E_LUAU_API`) and an argument error it can see statically (`E_LUAU_TYPE`) as `<file>:<line>: <message>`. The check follows direct `sega.a.b` access; the run-time gates also apply to aliases.

## Faults

A script that errors, runs out of its instruction budget or memory, uses a binding without its capability, passes a bad argument or calls a binding in the wrong phase **faults**: its staged output is discarded, **only that mod** is disabled for the session, and the host carries on. The diagnostic is `E_MOD_FAULT cause=<cause> mod=<id> callback=<name> frame=<n>: <message>`. Causes: `error` (runtime error), `budget`, `stack`, `watchdog` (host timing; the run is marked non-deterministic), `memory`, `capability`, `range`, `phase`, `state`. A syntax error is `E_LUAU_SYNTAX` at `mod build`.

## Editor setup (VS Code with luau-lsp)

```sh
segarecomp mod init my-hud --platform genesis --id my-hud --template luau --rom-sha256 <sha256 of your image>
segarecomp mod check my-hud
```

`init --template luau` writes `types/segarecomp.d.luau` (the generated declarations), `.luaurc` (strict mode) and `.vscode/settings.json` pointing `luau-lsp.types.definitionFiles` at the declarations. Install the [Luau Language Server](https://github.com/JohnnyMorganz/luau-lsp) extension yourself; nothing is shipped here. `mod check` is the checker that gates your package; the language server gives you full type inference as an extra. The same declarations work with the command line analyzer if you have it installed:

```sh
luau-analyze --definitions=types/segarecomp.d.luau scripts/main.luau
```

(The Luau analysis module is not part of this product, so this command is documentation: no CI job installs `luau-analyze`.)

## The HUD example, end to end

[`platforms/genesis/sdk/examples/luau-hud`](../../platforms/genesis/sdk/examples/luau-hud/README.md): a synthetic, ROM-free, Luau-only score/lives panel.

```sh
segarecomp mod build   platforms/genesis/sdk/examples/luau-hud --out luau-hud.segapatch
segarecomp mod install luau-hud.segapatch --rom fixture.rom --library lib
segarecomp mod session lib/mods/<package_identity>.segapatch --rom fixture.rom --frames 60 --bmp last.bmp
```

`install` classifies the package **Luau-only** (`"approval_kind":"consent"`): no native-code approval is asked, and the install sheet states "includes scripts that run while you play ... not a security guarantee" with the capabilities listed. `session` prints a SHA-256 for the first frame, the last frame and the whole session; CI pins them (`tests/fixtures/mod_luau/hud_session.json`) and an independent Python implementation re-derives the frame hash of a rect-only script. The session is a **fixture**: a synthetic 320x224 picture seeded by the fixture image, not the Genesis machine.

## Test coverage of the policy categories (SEG-133-T005 section 8)

| Category | Test |
| --- | --- |
| `library-surface`, `mod-isolation`, `memory-exhaustion`, `cpu-exhaustion`, `determinism` | `luau_host_test` (F06), extended by `luau_api_test` (string.rep and table bombs, buffer bomb, infinite and nested loops, pcall around loops, deep and mutual recursion, golden random sequence, same-run determinism, two-VM isolation) |
| `escape-metatable` | `luau_api_test` (string metatable, library and global edits, `rawset`, `setmetatable`/`getmetatable` on `sega`) |
| `binding-abuse` | `luau_api_test` (22 bad calls, phases, read-only surface, no host handles), `mod_luau_api_test` |
| `bytecode-injection` | `luau_host_test` (provenance), `mod_luau_test`, `luau_api_test` (`loadstring`/`load` of bytecode are absent) |
| `state-integrity` | `luau_api_test` (canonical serialization, 12 save refusals, 12 restore refusals (10 malformed blobs, a mod without `load()`, an error in `load()`); the `MODSTATE` container is M05) |
| `diagnostic-hygiene` | `luau_api_test`, `mod_luau_api_test` (bounded, no path/address) |
| `compiler-input` | `luau_api_test` (deep nesting, 100 KB literal, 300 live locals), `mod_luau_test` (compile limits) |
| `approval-semantics` | `mod_luau_api_test` (data / Luau-only / native and mixed install classes) |

Portability: the pipeline is integer-only; `mod_luau_api_test` asserts the same pinned session hash on every platform in the CI matrix (Linux, Windows, macOS). Platforms not exercised by CI (and anything not run by the maintainer locally: only Linux aarch64) are **not validated**.
